Proportion / Prevalence Meta-Analysis

Pool single proportions (events out of a total) across studies with DerSimonian-Laird random effects, using either the logit or the Freeman-Tukey double-arcsine transform. Back-transformed pooled proportion, I² and a forest plot. Fully offline — no network, no dependencies.

Input

Events (xi) must be a whole number between 0 and the total (ni).
Variance-stabilising transform
Provenance. Logit: yi=log(p/(1−p)), vi=1/xi+1/(ni−xi); add 0.5 to both cells only when xi=0 or xi=ni. Freeman-Tukey: double-arcsine with vi=1/(4ni+2); pooled value back-transformed with Miller's harmonic-mean inverse (metafor transf.ipft.hm). DerSimonian-Laird τ², Higgins-Thompson I². Validated against metafor rma(measure="PLO"/"PFT").
